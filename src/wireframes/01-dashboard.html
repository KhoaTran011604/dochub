Structural notes

  • Left icon rail is the persistent app shell (also on screens 2-4) — replaces the old top-bar-only / back-button / crumb mix with one consistent nav pattern. Only Dashboard exists as a global entry today (YAGNI — no invented Shared/Trash/Settings items).
  • Card = one Project; left accent bar = per-project brand color, reused on the public view (screen 5); brightens to the accent gradient on hover (no layout-shifting scale transform).
  • Status badge, doc count, owner all come from real fields/queries — no schema beyond projects.status. Filter + free-text search is live client-side for <50 items.
  • Hover reveals quick actions: Share, Archive. Duplicate dropped — no backing endpoint (sign-off 2026-09-30).
  • Click card → Project Workspace (screen 2). + New opens a create-project modal (name, client, brand color/logo optional).
  • Empty state: illustration + "Create your first project" CTA.
