Structural notes

  • Left icon rail (shared shell, screens 1-4) sits outside the tree column — ◆ always returns to the Dashboard.
  • Left tree: Notion-style nested nodes (Space > Folder > Document); icons differ for page vs form; drag to reorder; + per row adds a child; right-click = rename/move/delete/restore. No duplicate — dropped, no endpoint. Selected node gets a tinted row + gradient left-bar (see "MSA Draft" above) so the active doc reads at a glance in a long tree.
  • Trash opens a slide-over: flat list of trashed top-level nodes, Restore per row; system admins also see Delete permanently (typed-confirmation modal).
  • Right permission panel is scoped to the selected node — rows show user/role grants, "Inherited from X" until an override exists (badge → Custom).
  • + Override breaks inheritance for node-specific ACL. Publish… toggles the public read-only link for this subtree → feeds screen 5.
  • Main area swaps by node type: BlockNote editor for page (screen 3), rjsf form for form (screen 4).
