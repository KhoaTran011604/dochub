Structural notes

  • The old lone "← Back" link is gone — navigation is now the shared icon rail (◆ → Dashboard) plus a clickable breadcrumb, same pattern as screen 2.
  • Per-block drag handle + ⋮ menu (turn into, duplicate, delete, color) on hover, left of block.
  • Selecting text shows the floating format toolbar — no inline comment thread in MVP (dropped, no endpoint; sign-off 2026-09-30).
  • Viewer role: whole editor renders read-only — no slash menu, drag handles, floating toolbar, autosave/AI — same treatment as screen 5's public render.
  • ✦ Generate with AI opens a prompt panel and runs a background job that creates a new sibling draft page ("AI Draft: <title>") for review — it does not insert blocks inline. Pending/failed states show as a toast + entry in an AI jobs tray.
  • 409 conflict banner appears on save collision (shown above).
