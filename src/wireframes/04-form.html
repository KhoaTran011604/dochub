Structural notes

  • Rail + breadcrumb replace the old "← Back" link, same as screen 3 — one nav pattern across every authenticated screen instead of three different ones.
  • Widgets map 1:1 from JSON-schema types: string→text, number→numeric, enum→select, object→bordered fieldset (collapsible if deep), array→repeatable rows with add/remove.
  • Required fields marked *; inline validation on blur + on submit; errors under field and summarized at top if submit is blocked. Submit uses the gradient CTA style; disabled/muted (no gradient) while blocking errors remain.
  • Save = persists draft (documents.status='draft'). Submit = validates + sets status='submitted': fields become read-only, badge shows "Submitted", editor/admin see a Reopen button in place of Save/Submit; viewers always read-only.
  • Same permission panel from screen 2 applies at the form level, not per-field.
