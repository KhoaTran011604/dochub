Structural notes

  • No admin icon rail here — intentional (screen 5 stays login-free with no internal nav); it inherits the same accent-gradient tokens for its theme-color bar/active nav item instead.
  • Only nodes the shared link grants viewer+ on appear in the tree — filtered server-side, not just hidden in UI.
  • Branding: client logo replaces company logo; theme color drives accent (links, active nav, top bar); falls back to default branding if unset.
  • page docs render BlockNote content read-only. form docs render as a label/value summary (not editable inputs) — nested objects as sub-sections, arrays as lists.
  • Mobile: sidebar collapses to a hamburger/drawer, single-column reading layout.
  • No login wall, no internal nav/branding, no edit affordances anywhere on this view.
  • No comment/"request change" affordance in MVP — comments table exists as an unwired schema placeholder only (phase-01), reserved per sign-off 2026-09-30.
